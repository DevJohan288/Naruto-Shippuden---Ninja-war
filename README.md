# 🍥 Naruto Shippuden - Ninja War

Un juego de **combates por turnos inspirado en Naruto Shippuden**, desarrollado en **Unity** con un estilo visual **Pixel Art**.

## 🎮 Sobre el proyecto

**Naruto Shippuden - Ninja War** es un proyecto desarrollado en Unity que busca recrear combates ninja mediante un sistema de turnos.

Los jugadores podrán enfrentarse utilizando diferentes personajes, ataques y habilidades inspiradas en el universo de Naruto.

## ⚔️ Características

- 🎮 Sistema de combate por turnos.
- 🍥 Personajes inspirados en Naruto Shippuden.
- 🥷 Sistema de enemigos.
- 💥 Ataques y habilidades especiales.
- ❤️ Sistema de vida y daño.
- 🎨 Estilo visual Pixel Art.
- 🕹️ Desarrollado en Unity.

## 🛠️ Tecnologías

- **Unity**
- **C#**
- **Pixel Art**
- **Git & GitHub**
